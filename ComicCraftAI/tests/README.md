# ComicCraft

AI Comic Story Creator built with:

- FastAPI
- Jinja2
- Google Gemini
- Hugging Face Diffusers
- Stable Diffusion
- FPDF
- Pillow

## Features

- Story prompt
- Character name
- Setting
- Story tone
- Art style
- Five-panel comic outline
- AI narration
- AI dialogue
- AI image generation
- Comic preview
- PDF export
- JSON API
- Swagger API documentation
- Automated tests
